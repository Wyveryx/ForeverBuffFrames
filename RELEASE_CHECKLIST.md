# Pre-publish UI checklist

This checklist belongs to the Phase 13 release gate defined in
[ROADMAP.md](ROADMAP.md). It does not authorize new feature work.

- Redesign dropdown and media-picker spacing as one consistent visual pass.
- Increase row height and internal padding.
- Keep labels, preview controls, selection markers, and scrollbars from competing for space.
- Verify long localized labels at every supported configuration text size.
- Inspect every dropdown in game before publishing the next release build.
