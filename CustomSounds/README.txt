ForeverBuffFrames custom sounds

1. Close World of Warcraft completely.
2. Copy an .ogg or .mp3 file into this folder.
3. Start WoW and open ForeverBuffFrames.
4. For a buff, open Buff Alerts and add the relative path above the learned-buff list.
5. For a debuff, enter the path in the desired row on Debuff Alerts.
6. Use a sound selector to assign the file, then Preview where available.

The full stored path will be:
Interface\AddOns\ForeverBuffFrames\CustomSounds\my-sound.ogg

WoW cannot discover a new sound file copied into the folder while the client is
already running. Restart the client after adding or replacing files.
